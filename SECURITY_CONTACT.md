# Security Contact and Vulnerability Disclosure

If you believe you found a security vulnerability in Schrödinger Mail, please report it privately.

## Private reporting channel

- Preferred: open a private security advisory in GitHub ("Report a vulnerability")
- Alternative: email the maintainers at `security@schrodinger-mail.dev`

If the email is not yet configured for your deployment, replace it with your team's monitored security mailbox before making the repository public.

## What to include

- A clear description of the issue
- Affected components/files/endpoints
- Reproduction steps or proof of concept
- Expected impact and threat scenario
- Suggested mitigation (if available)

## Disclosure policy

- We acknowledge reports as soon as possible
- We triage and confirm severity before public disclosure
- We coordinate a fix and release timeline with reporters
- We credit reporters who want attribution

Please avoid public disclosure until a fix is available and users have had time to upgrade.
