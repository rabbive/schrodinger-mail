Why Post-Quantum?

Quantum computers running Shor's algorithm can break RSA, ECDSA, and ECDH in polynomial time. While large-scale quantum computers don't exist yet, adversaries may already be recording encrypted traffic for future decryption — the "Harvest Now, Decrypt Later" attack. NIST finalized the first post-quantum cryptographic standards (FIPS 203: ML-KEM, FIPS 204: ML-DSA) in August 2024 to address this threat. This email client implements Kyber768 (ML-KEM-768) for key encapsulation and Dilithium3 (ML-DSA-65) for digital signatures, both at NIST Security Level 3.

⚠ Zero-Knowledge Disclaimer
This prototype stores private keys server-side for demonstration purposes. In a production system, private keys should never leave the client device. A true zero-knowledge architecture (like ProtonMail or Tuta) would generate and store keys exclusively in the browser, encrypting them with the user's password before any server storage.
